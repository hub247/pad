# Shimmer Pads V5

## Novidades
- Loop independente do pad e do metrônomo.
- O loop reinicia sem fade.
- O pad faz fade-in apenas quando o usuário inicia e fade-out apenas quando o usuário para.
- Botões Iniciar os dois e Parar tudo.
- Volumes independentes, BPM, compasso, Tap Tempo e setlist.

## GitHub
Substitua `index.html`, `manifest.webmanifest`, `sw.js` e `icons`. Mantenha seus áudios nas pastas existentes.
