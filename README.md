# Shimmer Pads V3

Inclui design responsivo para celular e tablet, Web Audio API, Media Session, Wake Lock, download offline dos 12 MP3, favoritos, histórico, setlist, crossfade e PWA.

## Áudios
Coloque na pasta `audio`: C.mp3, C#.mp3, D.mp3, D#.mp3, E.mp3, F.mp3, F#.mp3, G.mp3, G#.mp3, A.mp3, A#.mp3 e B.mp3.

## Offline
Depois de publicar em HTTPS, abra o app online e toque em **Baixar 12 pads**. Aguarde a confirmação antes de testar sem internet.

## Áudio em segundo plano
A V3 usa mídia HTML, Web Audio API e Media Session. Navegadores e sistemas operacionais ainda podem suspender páginas em segundo plano, especialmente no iPhone/iPad. Para garantia de reprodução contínua com tela bloqueada, será necessário empacotar/testar como aplicativo nativo.
